# Mighty Party — fiches des 22 cartes communes

Collecte du 23 octobre 2026. **Référence communautaire historique, non vérifiée dans le jeu actuel.** Les sources individuelles datent de décembre 2020 à février 2021.

Les tableaux de statistiques sont ceux de **Reborn 0**, sans Soulbind ni bonus temporaire. Les coûts communs à toutes ces cartes sont dans la [synthèse](../../mighty-party-reference.md). Les valeurs structurées sont dans [common-cards.json](common-cards.json).

ATQ = attaque ; PV = points de vie. C1/C2 désignent les capacités décrites dans chaque fiche. Une valeur se maintient entre deux paliers renseignés. « Verrouillée » est différent d’une capacité active de valeur zéro.

Un libellé sans déclencheur explicite est conservé sans lui ajouter « à chaque tour ». Les variantes invoquées ont leur propre niveau ; ce niveau est distinct du niveau de leur invocatrice.

Pour une invocation : `ATQ/PV (niveau propre du jeton)`. Pour les autres effets : valeur de la capacité, avec l’unité indiquée dans C1/C2. Les bonus de renaissance sont conservés séparément dans le JSON.

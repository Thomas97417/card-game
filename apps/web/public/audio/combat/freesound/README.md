# Sons de combat Freesound

15 fichiers originaux récupérés le 28 octobre 2026, avec leurs aperçus MP3 HQ.
Chaque fiche Freesound affichait la licence CC0 au moment du téléchargement.
Les originaux sont conservés sans transformation dans `originals/`.
Ouvrir `index.html` pour écouter les aperçus et accéder aux originaux.

Les combats utilisent ces originaux dans un sprite WAV préparé par
`scripts/generate-combat-audio.mjs` et `scripts/combat-audio-edits.json` : silences
retirés, durées adaptées, fondus et niveaux équilibrés. Le son du héros utilise
un extrait de 1,1 seconde. Trois variantes accompagnent les attaques de mêlée.
Les lecteurs de cette galerie font écouter les aperçus des sons complets.

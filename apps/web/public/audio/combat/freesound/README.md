# Sons des cartes

33 enregistrements originaux Freesound CC0 conservés dans `originals/`.
La galerie `index.html` fait écouter les 46 extraits utilisés par le jeu.

Les profils de `combat-audio-profile.ts` distinguent le corps à corps, la distance,
les rôles (archer, mage, prêtre, dragon, combattant, créature…) et les éléments.
Les évolutions et les définitions des renforts conservent leur identité sonore.

La pose sur le plateau utilise trois prises de pièces et une variante lourde,
puis un accent bref lié à la créature. Aucun son ne tourne en boucle.

Reconstruction : `FFMPEG=/chemin/vers/ffmpeg bun scripts/generate-combat-audio.mjs`.
Les coupes et ajustements sont décrits dans `scripts/combat-audio-edits.json` ;
les auteurs, licences et empreintes sont dans `docs/combat-audio-sources.json`.
